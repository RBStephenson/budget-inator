# Security Policy

## Supported Versions

This is a personal-use application. Security fixes are applied to the latest version on `main` only.

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Instead, report them via GitHub's private [Security Advisories](https://github.com/RBStephenson/budget-inator/security/advisories/new) feature, or email [rbrent.stephenson@gmail.com](mailto:rbrent.stephenson@gmail.com).

Include:
- A description of the vulnerability and its potential impact
- Steps to reproduce
- Any suggested mitigations

You can expect an acknowledgement within 7 days.
